# Sandbox workspace

This is the only folder the sandbox can see.
Inside the container it is mounted at `/workspace`.

- `hello.py` prints a greeting and the Python version.
- `rfc2324-coffee-pot.txt` is RFC 2324, the April Fools' Day standard for controlling coffee pots over HTTP.
- `AGENTS.md` holds the project notes that lesson 6 loads into the system prompt.
